# Movie Recommendation System

A content-based movie recommendation engine built in Python using scikit-learn and pandas. This project utilizes TF-IDF (Term Frequency-Inverse Document Frequency) vectorization to convert movie plot overviews into numerical feature vectors and computes Cosine Similarity to recommend the top 5 most similar movies based on plot context.

## Key Features
* **Dataset Processing:** Cleans and processes movie metadata and plot overviews.
* **TF-IDF Vectorization:** Transforms natural language text into high-dimensional matrix representations while removing standard stop words.
* **Cosine Similarity Engine:** Calculates geometric angles between feature vectors to identify content matches.
* **Google Colab Integration:** Fully configured to load datasets and execute seamlessly in cloud notebook environments.

## Tech Stack
* **Language:** Python
* **Libraries:** Pandas, Scikit-Learn, NumPy
* **Environment:** Google Colab / Jupyter Notebook
